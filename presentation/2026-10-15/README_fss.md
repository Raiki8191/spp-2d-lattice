## 定義と説明の区別

- S6/S7はスケーリングの仮定。uは説明用の補助記号で、関数の具体形は決めない。
- S8は平均Sの最大位置。各試行のピーク位置を平均する量、最大要求落下の位置、ピークの高さとは区別する。
- S9の符号は原文どおり。ピークのスケーリング変数が一定、補正を無視できる等の前提から、シフト則を理解する途中計算を板書へ置く。bの符号や近づく側は固定しない。
- S10の`P(p_c)`は`〈P(p=p_c,N)〉`の簡略表記で、N依存が省略されている。S11/S12の`P_c(N),S_c(N)`はサイズごとの`p_c(N)`での平均量。
- F(0)・F(−b)を適切な有限の正定数とみなす等の前提の下で、べき乗則と対数の傾きを説明する。SPPの定義からの厳密な証明や不連続性の証明とは扱わない。
- Fig.S1の原論文の手順は、候補pごとのPのサイズ依存を回帰し、決定係数r²でp_cを調べるもの。そのp_cとp_c(N)のずれから、1/ν̄やシフト係数を推定する。
- Fig.S2は両対数、点は平均値、線は対数変換後の回帰。原図は視認性のため誤差棒を省略し、縦値を10^Xで割る。X=0,1,2,3はC=1,2,3,Nに対応し、旧スライド10の対数変数Xとは別。表示倍率は傾きを変えない。
- 制限なしの数値設定はC=N。著者は固定p_cに基づく指数に強い有限サイズ効果を指摘する。ERの指数を2Dの指数として用いず、N=L²という変数変換とν̄=2νの物理的対応の前提を区別する。

### 原典内の誤差表記差

SM Table S2のC=1、疑似臨界点側γ/ν̄は`0.35±0.001`。主論文PDF3／印刷047402-3左段の説明は`0.35±0.01`。どちらかを正しいと決めて書き換えず、原表をそのまま掲載して注記した。指数の±は補足Sec.IIIの回帰係数標準誤差という説明に対応し、95%区間とは呼ばない。p_cの±まで同じ算出方法とは断定しない。

## 再生成

リポジトリ直下で実行する。既存4ファイル、ローカル原典PDF、PowerPoint、PythonのMatplotlib/Pillow、Poppler、LuaLaTeXが必要。追加インストール・課金サービス・SPPシミュレーションは不要。

```powershell
python -B presentation/2026-10-15/prepare_fss.py
powershell.exe -NoProfile -ExecutionPolicy Bypass -File presentation/2026-10-15/build_powerpoint_with_fss.ps1
python -B presentation/2026-10-15/build_board_fss.py
python -B presentation/2026-10-15/validate_with_fss.py
```

元の`prepare_01_10.py`／`build_powerpoint_01_10.ps1`／`build_board_01_10.py`のmain処理は実行しない。新スクリプトは必要な純粋関数だけ再利用する。旧板書の保護SHAが変わった場合、新しい版へ無断適応せず停止する。

PowerPointは既存COM環境を使用する。専用artifact-toolランタイムが今回のツールにないため、そのimport検証を実施したとは報告しない。日本語フォントは参照資料のMeiryoを維持する。数式はLaTeXから高解像度PNGへ再生成し、その他の本文は編集可能なテキスト。旧10枚のテキスト・図形を画像へ置き換えない。
