## Table S2と主論文Table I

Table S2は補足資料の第2表で、ERネットワークのconventional ensembleによるFSS推定値。criticalは全N共通のp_c、pseudo-criticalはS8の各Nの平均Sピーク位置p_c(N)でP・Sを評価する。これらの見出しは連続／不連続の分類ではない。

C=∞の原表を再確認した。固定p_cのβ/ν̄=0.04±0.01、γ/ν̄=0.15±0.01に対し、平均Sピーク位置では0.24±0.01、0.53±0.01。C=1,2,3では両評価位置の指数比は比較的近い。原表の値・列・誤差は修正せず、全行全列を画像で直接引用する。

主論文PDF2のTable Iはevent-based ensembleと明記する。各runの**単一辺削除による最大クラスターの最大落下**を基準に状態を選び、各runの位置で観測してから試行平均する。平均S曲線の最大位置とも、要求1回で経路全体を削除した前後のジャンプとも別の定義である。C=∞のTable Iはβ/ν̄=0.21±0.01、γ/ν̄=0.55±0.01。

SMのS13/S14は最大単一辺落下の直後p⁺／直前p⁻を区別し、両側の観測量を報告する。Table I単独はどちら側の列かを一意に明記せず、SM Tables S3/S4のaverage列はいずれもTable Iと同値。資料では片側だけと補って断定しない。平均イベント位置で平均曲線を評価することと、runごとにイベント位置で評価してから平均することも一般に異なる。

## 有限サイズ効果の根拠と限界

SM PDF3／Sec.IV.B末段は、制限なしの固定p_cで得た指数は強い有限サイズ効果を受ける一方、p_c推定は影響されないと著者が評価する。これを19の下部・ノート、23の原表下、板書12ページに記載した。主論文PDF3の説明も照合した。

Table S2の二つの評価位置での数値差と、著者による有限サイズ効果の説明を分ける。差自体が原因の数学的証明という意味ではない。p_c推定についても著者の数値的評価として限定し、有限サイズ効果が厳密に存在しないと証明されたとは述べない。

原典ERの指数を2D格子へそのまま適用せず、2D制限なしSPPで無限サイズにも有限ジャンプが残るかを今回の表から結論しない。C=1のピークγ/ν̄の誤差がTable S2で0.35±0.001、主論文本文で0.35±0.01という既知の相違は、原表を訂正せず板書の質問時補足へ移した。指数の±を95%区間と呼ばない。

## 生成と保持の方法

Ver.2のPowerPointコピーを既存COM環境で開き、19・20・23だけを編集する。元パッケージへ移すのも、その3枚のスライドXML・画像参照・ノートXMLだけ。他20枚と共有資源は元bytesを保持する。

スライドPDFは完成PPTXをPowerPointで再読込して改訂3ページを出力し、変更対象外20ページをVer.2 PDFから直接連結する。板書も元PDFの最初11ページを抽出して、新しい最後の1ページとpdfuniteで結合する。Markdownの旧1〜18部分は生bytesのprefixとして保持する。

旧生成コードのmain処理は実行せず、必要な純粋関数のみ再利用する。既存のPowerPoint、Python（Matplotlib・Pillow）、Poppler、LuaLaTeXを使用する。専用artifact-toolによるimport検証済みとは報告しない。追加の有料サービス、研究シミュレーション、新しい研究データ・回帰を利用しない。

リポジトリ直下で実行：

```powershell
python -B presentation/2026-10-15/prepare_ver3.py
powershell.exe -NoProfile -ExecutionPolicy Bypass -File presentation/2026-10-15/build_powerpoint_ver3.ps1
python -B presentation/2026-10-15/build_board_ver3.py
python -B presentation/2026-10-15/validate_ver3.py
```

中間とQAは `.build/ver3_slides/`、`.build/ver3_board/`、`.build/ver3/`。原図の独立照合は `.build/ver3_sources/`。原論文PDF、QA画像、一時ファイル、無関係な変更をGitへ追加しない。
